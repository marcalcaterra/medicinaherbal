# MAR — Terapia de Medicina Herbal

Página inicial para agendar turnos e ingresar a la cuenta.

## Incluye

- Logo de MAR arriba
- Pestaña **AGENDÁ TU TURNO**
- Pestaña **INGRESÁ A TU CUENTA**
- Login al pie de la página

## Subir a GitHub

```bash
cd sitio-turnos
git init
git add .
git commit -m "Primera version MAR medicina herbal"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/TU-REPO.git
git push -u origin main
```

En GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**

La web queda en `https://TU-USUARIO.github.io/TU-REPO/`
